# TaskFlow 开发与构建

## 环境要求
- Node.js 18+ （https://nodejs.org 下载）
- Rust / Cargo（https://www.rust-lang.org/tools/install ，开发和构建需要）

## 第一次启动（开发模式）

打开终端，进入 TaskFlow 目录：

```bash
cd TaskFlow

# 安装依赖（仅需执行一次）
npm install

# 启动 Tauri 开发模式
npm.cmd run dev
```

等待约 10 秒，应用窗口会自动弹出。

---

## 本地便携版

执行构建后，便携版位于：

`release/小光任务.exe`

双击即可运行。

---

## 构建便携版

```bash
npm.cmd run build
```

构建脚本会自动把 `src-tauri/target/release/小光任务.exe` 复制到：

`release/小光任务.exe`

> 说明：项目已完全迁移到 Tauri，Electron 版已于 2026-06-11 移除（git 历史中可找回）。

## 功能说明

| 操作 | 方式 |
|------|------|
| 添加任务 | 顶部输入框，回车确认 |
| 设置截止日期 | 添加任务时选择日期，或悬停任务后用日期控件修改 |
| 打开任务详情 | 单击任务标题 |
| 编辑备注 / 优先级 / 标签 | 打开任务详情面板后编辑 |
| 设置重复任务 | 任务详情面板中选择每天 / 每周 / 每月 |
| 到期提醒 | 应用启动后自动提醒今天截止和已逾期任务 |
| 完成任务 | 点击左侧复选框 |
| 编辑任务标题 | 双击任务文字 |
| 添加子任务 | 鼠标悬停，点击 + 按钮，输入框变为子任务模式 |
| 删除任务 | 鼠标悬停，点击 × 按钮 |
| 拖动排序 | 拖拽任务行上下移动 |
| 键盘操作任务 | ↑/↓ 在任务间移动，空格勾选完成，回车打开详情 |
| 撤销删除 | Ctrl + Z，或点击提示条上的「撤销」 |
| 逾期任务顺延 | 悬停逾期任务，点击「顺延到今天」按钮 |
| 搜索 / 筛选 | 任务列表顶部搜索框、状态分段控件、日期筛选 |
| 智能视图 | 左侧「今天」「近 7 天」「已完成」快速查看 |
| 新建项目 | 左侧栏底部「新建项目」按钮 |
| 重命名项目 | 右键项目名 → 重命名 |
| 删除项目 | 右键项目名 → 删除项目 |
| 备份数据 | 左下角导出/导入按钮，或进入设置页操作 |
| 切换主题 | 设置页「主题配色」选择晨雾 / 墨蓝 / 森林 / 石墨 / 暮杏 |
| 桌面组件 | 设置页「桌面组件」选择项目或智能视图，并点击「显示组件」 |
| 组件右键菜单 | 在组件上右键：置顶、紧凑、折叠、悬浮球、透明度、显示数量 |
| 组件悬浮球 | 点组件标题栏 ◐ 按钮缩成小球并吸附到屏幕左/右边缘半隐；悬停滑出，单击恢复，可沿屏边拖动 |
| 组件折叠方向 | 折叠/展开自动以靠近屏幕边缘的一侧为锚点，放在屏幕下方展开时向上伸展不再位移 |
| 组件双击任务 | 双击任务在主窗口打开对应详情 |
| 全局快速添加 | 默认 Ctrl+Alt+N（设置页可改/停用），任何界面弹出快速输入框；Enter 添加并关闭，Ctrl+Enter 连续添加 |
| 单实例运行 | 重复打开 exe 不会启动第二份程序，而是唤起已运行的主窗口 |
| 组件内存优化 | 桌面组件窗口按需创建，隐藏 5 分钟后自动释放 |
| 组件删除撤销 | 组件内删除任务后 6 秒内可点击「撤销」 |
| 托盘后台运行 | 点击主窗口关闭按钮后，程序隐藏到右下角托盘 |
| 托盘菜单 | 右键托盘图标，可显示主窗口、显示/隐藏桌面组件、退出 |
| 导出诊断日志 | 设置页「诊断日志」区域导出 |
| 清空诊断日志 | 设置页「诊断日志」区域清空 |

## 数据存储位置

数据自动保存在应用数据目录，重装应用通常不会丢失：

`%APPDATA%\com.personal.taskflow-lite\taskflow-data.json`

（实际路径可在设置页「应用信息」中查看。）

## 自动备份

应用启动时会自动创建一份备份，导入外部备份前也会自动创建一份备份。

默认保留最近 30 份：

`%APPDATA%\com.personal.taskflow-lite\backups`

## 数据版本与诊断

应用数据包含 `schemaVersion` 字段，旧数据会在读取时自动补齐新字段。

设置页会显示日志路径和最近诊断日志，便于排查导入、启动和数据恢复问题。

## 发布注意事项

- 应用图标资源位于 `assets/icon.svg` 和 `assets/icon.ico`。
- `assets/icon.ico` 可通过 `npm.cmd run generate:icon` 重新生成。
- Tauri 构建统一经过 `scripts/build-tauri.ps1`，会将用户目录和工作区路径映射为通用占位符，避免发布包携带编译机路径。
- `release/`、`dist/` 和 `src-tauri/target/` 都是可重新生成的产物，不提交到 Git。
- 正式公开分发前建议配置代码签名证书。


## 架构说明

项目已于 2026-06-11 完成从 Electron 到 Tauri 1.x 的迁移并移除 Electron 代码（历史见 git 记录）。
桌面组件窗口按需创建、隐藏 5 分钟自动释放；数据常驻内存、防抖落盘。

注意：应用自身进程内存（任务管理器中的 小光任务.exe）通常仅 10-30 MB，完整占用需把 msedgewebview2.exe 子进程计入，整体约为同类 Electron 应用的 1/3。

## 桌面组件与托盘验收

1. 打开 `release/小光任务.exe`。
2. 进入设置页，找到「桌面组件」。
3. 选择要显示的项目，点击「显示组件」。
4. 桌面组件可以拖动位置、调整大小、切换置顶、切换紧凑模式。
5. 点击主窗口右上角关闭按钮，主窗口会隐藏到系统托盘，程序继续后台运行。
6. 右键托盘图标，可以重新显示主窗口、显示/隐藏桌面组件，或退出程序。
