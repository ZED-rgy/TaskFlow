# 今日计划与移动端操作改进

## 使用方式

- 默认打开今日计划：直接写下今天想做的事，或从已有项目挑选任务。
- 项目负责归类，`plannedDate` 表示打算哪天做，`dueDate` 表示最晚何时完成；两者独立。
- 未选择项目的新任务放入收集箱。现有“今日待做”等项目保持不变，不自动合并或删除。
- 计划日期早于今天的未完成任务进入“待重新安排”，可继续今天、另选日期或取消计划。计划日期本身不会造成逾期。
- 今日到期及逾期任务另列为截止提醒，由用户决定是否加入当天计划。
- 完成后折叠到今日完成区域，历史按本地完成日期查看；不会自动删除完成任务。
- 今日计划顺序使用 `planPosition`，不改变项目内 `position`。桌面组件的今日视图也使用计划日期。

## 移动端操作

- 项目旁的更多按钮和长按菜单可重命名、删除；弹层脱离侧边栏裁剪和遮罩，定位限制在屏幕内。
- 项目列表中的重命名输入引用支持 Vue 列表 ref，并避免 Enter 后 blur 重复提交。
- 项目任务列表进入“调整任务顺序”后使用手柄拖动；搜索或筛选时禁用重排，避免错误改写隐藏任务的顺序。
- 任务行更多菜单支持加入今日计划、选择计划日期、取消计划、移动项目、查看详情及删除。移动根任务保留子任务归属。
- 删除沿用确认及撤销机制。排序失败仅回滚排序字段，保留并发编辑内容。

- 今日计划支持 Ctrl+N 聚焦新增、Ctrl+F 打开任务挑选搜索，命令面板新增操作保持在当前计划页。

## 数据与云端

本地 Rust 模型、更新命令、备份恢复和同步快照均保留计划日期及顺序。缺少这些字段的旧数据可直接读取。生成下一期重复任务时清除上一期计划，避免新任务立即落入待重新安排。

迁移 `20260905154459_preserve_task_plans.sql` 已应用到云端，触发器已读回确认启用，匿名及普通认证角色均无直接执行权限。旧版客户端提交缺少计划字段的任务时，云端保留最新快照中已有的计划；新版显式传 null 仍能取消计划。该保护不改变任务删除语义，也不替代原有并发同步检查。

共享任务历史记录计划日期，不记录纯排序变化。小组当天视图包含当天计划的共享任务，继续使用原有审批、项目可见性及排除任务检查。

## 验证

生产依赖通过官方 npm registry 审计，报告 0 vulnerabilities。

- `npm.cmd run verify`：规则、同步、日期时钟、桌面组件测试，前端构建，Rust 检查与 38 项测试，小组视图与数据库权限测试通过。
- 新增计划测试覆盖独立日期、跨天归类、根任务筛选、顺序与完成日期时区转换。
- Rust 测试覆盖新旧数据序列化、清空字段语义及重复任务不继承计划。
- 数据库测试覆盖旧版更新保留计划、新版清除计划，以及计划日期进入共享历史。
- 交互回归覆盖排序失败保留并发标题编辑，且不改变项目顺序。
- 隔离数据浏览器验收：移动端项目重命名、项目删除确认与执行、任务拖动排序、快捷删除和撤销；今日计划无截止日期新增、从项目挑选、继续昨日任务、取消计划、完成后折叠、独立排序。320/390 像素手机及 1280 像素桌面布局检查通过。

浏览器使用模拟本地后端，未修改真实用户任务。Android APK 构建不等同于真机验收；当前未连接 Android 设备，真实长按手势、软键盘与系统安装需在设备上复验。

安装包、体积、构建时间和 SHA-256 记录在本机 `release/daily-plan-verification.json`，构建产物不提交 Git。
