# TaskFlow 本地交互原型

这是用于确认新版视觉与交互方向的临时原型，不代表生产实现。

## 运行

```text
npm.cmd run dev:web
```

浏览器打开 `http://127.0.0.1:5173/?prototype=1&variant=atelier`。

原型入口仅在 Vite 开发模式启用，生产构建不会暴露此入口。

底部可以切换 5 套视觉方向，也可以用键盘 `←` / `→` 切换：

- `Atelier`：平衡型工作台，保留详情抽屉
- `Focus`：同一 Atelier 视觉下的专注流，按“现在 / 接下来 / 已完成”推进
- `Board`：同一 Atelier 视觉下的三列工作流，支持现在 / 接下来 / 完成
- `Command`：同一 Atelier 视觉下的命令优先工作台，强调快速添加和快捷键
- `Midnight`：深色工作台，验证夜间使用场景

## 本轮验证的问题

- 任务列表是否需要更明确的层级、状态和优先级信息
- 右侧详情抽屉是否比弹窗更适合快速编辑
- 命令中心（⌘ K）、智能分组和悬浮球是否能降低操作成本
- 完成任务、切换筛选、展开悬浮球时的动效是否足够克制

## 已落地的交互

- 点击任务行打开详情抽屉
- 点击复选框触发完成状态与勾选动效
- 搜索、待完成/已完成筛选、智能分组切换
- `⌘ K` 命令中心
- 悬浮球展开/折叠
- 主题方向实时切换

## 参考方向

- Linear：列表选择、命令中心和键盘优先操作
- Todoist：快速添加、筛选器和项目计数
- Things：Today / Upcoming 的分层组织与低干扰清单

确认方向后，将把有效部分吸收到正式 Vue 组件，删除原型入口与本文件。
